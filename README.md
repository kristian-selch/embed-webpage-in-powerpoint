# Embed webpage in PowerPoint

PowerPoint content add-in, der viser en live https-webside på en slide.
Hvert indsat element husker sin egen URL og zoom i .pptx-filen.

- `index.html` og ikonerne serveres via GitHub Pages.
- `manifest.xml` sideloades lokalt i `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/`.
